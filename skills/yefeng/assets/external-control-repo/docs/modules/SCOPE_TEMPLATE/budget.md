- 当前允许的活动实现 worktree：`0`
- 当前允许的待审候选：`0`

- 当前已启动角色：`0`

升级档位时可重新批准并行上限；模板建议值 `2 / 2 / 1` 不是当前授权，也不会自动写入机器状态。

Token 预算是上限，不是消耗目标。阶段边界记录估算区间、实际区间、剩余门槛和返工原因，不保存逐调用成本噪声。

同时保留最近一次用户确认的工期/工作量基线与当前估计。剩余工作增长超过章程阈值，或同一交付估计连续延期两次时，不静默覆盖旧基线；记录范围差异、改变估计的证据、已完成用户可见工作、内部使能工作和剩余产品路径，并在需要改变 Outcome Lock 时一次性询问。

除非本模块 Outcome Lock 或项目策略明确规定，不使用 P50、P80、置信区间、完成百分比或其他工作流的估时术语。证据不足时记录缺失的决策/验证和下一次重新估时边界，不制造精确度。
